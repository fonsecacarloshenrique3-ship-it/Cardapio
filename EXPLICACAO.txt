1. PERGUNTAS TEÓRICAS DA AULA 03 (RESPOSTAS COM MINHAS PALAVRAS)

Q1: O que é um Service Worker (com minhas palavras)?
R: O Service Worker é um script JavaScript especial (sw.js) que roda em segundo 
   plano no navegador, separado da página web visual. Ele funciona como um 
   "intermediário" (ou proxy) entre o aplicativo e a internet, interceptando 
   todas as requisições de arquivos. É ele quem permite que o app funcione 
   mesmo sem conexão com a internet (offline) e torna o app instalável no celular 
   ou computador como uma PWA.

Q2: O que é a estratégia "Cache Primeiro" (Cache First)?
R: É a regra de busca de arquivos onde o Service Worker primeiro verifica se 
   o arquivo solicitado (HTML, CSS, JS, imagens) já está salvo na memória local 
   do navegador (Cache Storage). 
   - Se o arquivo for encontrado no cache, ele é entregue instantaneamente (rápido e offline).
   - Se NÃO for encontrado no cache, aí sim ele faz a requisição pela internet (rede).
   Essa estratégia é ideal para os arquivos essenciais do aplicativo que não mudam a toda hora.


2. AS 3 PEÇAS DA PWA NO PROJETO

1. O Site / Aplicação (index.html, style.css, app.js):
   - Sistema de cardápio digital com filtros de categorias (Lanches, Porções, Bebidas, Sobremesas).
   - Busca em tempo real e adição ao carrinho com controle de quantidade.
   - Cálculo automático de totais, formulário de atendimento e envio para WhatsApp.

2. O Manifest (manifest.json):
   - Configuração de identidade do aplicativo com nome, ícones de 192px e 512px, 
     display "standalone" (abre em tela cheia sem barra do navegador) e cores de tema.

3. O Service Worker (sw.js):
   - Evento "install": Guarda todos os arquivos estáticos no cache (cardapio-tarefas-v1).
   - Evento "activate": Remove versões antigas de caches para manter o app atualizado.
   - Evento "fetch": Implementa a estratégia Cache Primeiro para rodar offline.
